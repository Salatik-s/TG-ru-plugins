# Плагины для TG-ru

Используйте этот репозиторий как шаблон, чтобы собрать свой набор ответов для [TG-ru](https://tg.24projects.ru/). Установленный плагин появляется в списке плагинов приложения. Откройте его, выберите шаблон, скопируйте текст и вставьте в нужный чат.

## Создать плагин

1. Нажмите **Use this template** и создайте публичный репозиторий на GitHub.
2. Укажите название, описание, идентификатор и версию в файле [`tgru-plugin.json`](./tgru-plugin.json). Оставьте файл в корне.
3. Добавьте от 1 до 12 шаблонов. В каждом укажите название и текст сообщения.
4. Сохраните изменения. Откройте `tgru-plugin.json` на GitHub и нажмите **Y**, чтобы получить [ссылку на точную версию файла](https://docs.github.com/en/repositories/working-with-files/using-files/getting-permanent-links-to-files).

## Установить в TG-ru

1. В сборке с поддержкой GitHub-плагинов откройте **Плагины → Добавить с GitHub**.
2. Вставьте ссылку вида `https://github.com/OWNER/REPO/blob/COMMIT_SHA/tgru-plugin.json`. Подходит и ссылка на тот же файл через `raw.githubusercontent.com` с полным SHA коммита.
3. Проверьте репозиторий, версию и шаблоны в окне предпросмотра. Нажмите **Установить**.

Для обновления укажите новую версию в манифесте, сохраните изменения в GitHub и установите плагин по новой ссылке. Список установленных плагинов позволяет включить, выключить или удалить каждый из них.

## Формат манифеста

Файл должен быть JSON в UTF‑8, размером до 16 КиБ. Используйте поля из примера.

| Поле | Значение |
| --- | --- |
| `schemaVersion` | Число `1` |
| `id` | От 3 до 48 символов. Начинается с маленькой латинской буквы. Далее допустимы маленькие латинские буквы, цифры и дефисы |
| `name` | Название плагина длиной до 64 символов |
| `version` | Версия вида `1.0.0`. От 1 до 4 цифр в каждой части |
| `description` | Краткое описание длиной до 240 символов |
| `templates` | Массив из 1–12 объектов с полями `name` (до 64 символов) и `text` (до 1 000 символов) |

Приложение читает JSON как данные. Формат поддерживает только текстовые шаблоны. Установленный плагин получает текст из манифеста и открывает буфер обмена по нажатию пользователя.
